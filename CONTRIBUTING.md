# CONTRIBUTING — как добавить бренд

1. **Проверь реестр**: бренда нет в `registry.csv`? Если есть, но не
   хватает темы — добавь недостающие файлы в существующую папку.
2. **Найди оригинал** (порядок предпочтения):
   - бренд-страница / press-kit провайдера (например `/brand`, `/press`);
   - CDN официального сайта (favicon.svg и т.п.);
   - GitHub организации провайдера;
   - репутабельные зеркала (Wikimedia Commons) и библиотеки
     (Simple Icons) — помечать `mirror`/`library`.
3. **Гигиена SVG** (обязательно, файл должен проходить санитайзеры):
   - без `<script>`, `on*`-атрибутов, SMIL (`<animate*>`);
   - без внешних `href`/`xlink:href` (внутренние `#id` — можно);
   - без `<style>`-блоков: заливки перенести в inline-атрибуты
     (`fill=...`), иначе санитайзеры режут блок и знак теряет цвет;
   - текстовый вектор (не растр в SVG), ≤100 КБ.
4. **Нейминг**: `brands/<slug>/{dark,light,color}.svg` (или `.png`
   fallback ≥256×256, прозрачный). Слаг — маленькие буквы/цифры/дефис.
   Недостающие темы можно получить перекраской (fill), не меняя
   геометрию path — пометь `derived` в реестре.
5. **Реестр**: добавь строку в `registry.csv`:
   `brand,file,theme,source_url,source_type,notes,sha256`
   (`sha256` — контрольная сумма файла).
6. **PR**: короткое описание — какой бренд, откуда, что проверено.

## Синхронизация с проектами

Проекты забирают файлы копией в свою статику (или скриптом синка).
Правило владельца: новый бренд в проекте → PR сюда в тот же день,
чтобы библиотека оставалась единым источником.
