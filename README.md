# 🎨 ai-brand-logos

**Общая библиотека логотипов AI-провайдеров для всех наших проектов.**

Один источник правды: брендовые знаки (SVG приоритет, PNG fallback) в
вариантах для тёмной/светлой темы, готовые к встраиванию в UI. Наполнена
на основе официальных бренд-китов, CDN и репутабельных зеркал.

## Зачем

Каждый наш продукт (myapi, CGENAI Platform, FlowLite, Hive, xfw, GoldenKey)
показывает карточки AI-провайдеров. Чтобы у всех было **одинаково и без
дублирования работы**: логотип живёт здесь, проекты забирают файлы и
подписываются на обновления.

## Структура

```
brands/<brand>/{dark,light,color}.svg   # темы: тёмная/светлая/универсальная
brands/<brand>/{dark,light,color}.png   # fallback, если SVG нет
registry.csv                            # машиночитаемый реестр всех файлов
CONTRIBUTING.md                         # правила добавления
```

Имя бренда = слаг (a-z0-9-). Пример: `brands/openrouter/dark.svg`.

## Формат файлов

- **SVG приоритет**: вектор, текстовый (без растра внутри), ≤100 КБ.
- Гигиена (обязательна): без `<script>`, `on*`-атрибутов, внешних
  `href`/`xlink:href`, `<style>`-блоков (заливки — inline-атрибутами),
  SMIL-анимаций. Файлы должны проходить типовые SVG-санитайзеры
  (например, `services/svg_sanitize.py` из myapi).
- **PNG fallback**: ≥256×256, прозрачный фон.
- Темы: `dark.svg` — знак для тёмного фона (светлый/брендовый),
  `light.svg` — для светлого, `color.svg` — универсальный брендовый.
  Если провайдер публикует один вариант — клонировать в `color` и
  пометить в реестре `derived` для недостающих тем (перекраска без
  изменения геометрии допустима, честно помечать).

## Реестр registry.csv

Колонки: `brand,file,theme,source_url,source_type,notes,sha256`.
`source_type`: `official` | `mirror` | `library` | `derived`.
Обновляется при каждом добавлении (скриптом или руками — главное,
чтобы строка была).

## Как использовать в проекте

1. Скопировать нужные `brands/<brand>/{theme}` в свою статику
   (или submodule/скриптом синка).
2. Указать источник в своей доке: «логотипы из ai-brand-logos».
3. **Не править файлы локально** — если нужен фикс/новая тема:
   PR сюда, затем синк всем.

## Как добавить бренд

См. [CONTRIBUTING.md](CONTRIBUTING.md). Коротко: проверить, что бренда
нет → найти оригинал (приоритет: бренд-кит/CDN/GitHub провайдера →
репутабельное зеркало → библиотека) → прогнать гигиену → положить по
неймингу → строка в registry.csv → PR.

## Правила для команд наших проектов

> **Договорённость владельца (21.11.2026):** если в своём проекте
> добавляете логотип нового провайдера — **обязательно делитесь им
> сюда** (PR), чтобы во всех проектах набор был одинаковым. И наоборот:
> новое появляется здесь → забираете синком.

## Лицензионная рамка

Логотипы — торговые марки провайдеров; собираются для номинативной
идентификации в UI (nominative fair use), без смысловых изменений.
Подробно по каждому файлу — в registry.csv (графа notes).
